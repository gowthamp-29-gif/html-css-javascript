## How to run
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. Use the dashboard buttons to enter HTML, CSS, or JavaScript.
4. Open any experiment from its list.
5. Use **Home** and **Back to Programs** on every experiment page.

## Verification
- All generated program files are separate HTML documents.
- All dashboard/list links are generated from the actual filenames.
- Relative navigation links were checked automatically.
- JavaScript snippets were generated as browser-executable code.
- The project uses no build step and can be opened directly from the extracted folder.
- A few source experiments explicitly require external APIs (for example weather/currency); those pages are implemented as browser demonstrations and show a clear offline/API-unavailable message when the external service cannot be reached.
